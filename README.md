# 同儕回饋編碼工具

瀏覽器內的九碼編碼介面，一筆一筆判讀，進度存在瀏覽器本機，不上傳任何伺服器。

## 使用

開啟網頁 → 逐筆判讀 → 右上「匯出 CSV」。

- 進度會自動存在這台電腦的這個瀏覽器裡，關掉網頁再打開會接續，不會從頭開始。
- 換電腦或換瀏覽器要用「匯入進度」把先前匯出的檔案讀回來。
- 編碼手冊在畫面右側，捲動可看完整定義、納入、排除與例子。
- 本筆若九碼皆無，按 `0` 或「確認無碼」。

## 注意

編碼期間請勿參照任何既有的編碼結果。這份工具刻意不顯示其他人怎麼編，獨立判讀才有信度意義。

## 資料

語料為去識別化後的同儕回饋文字，回饋者與受評對象均以代號表示（S01–S48、G1–G7）。
